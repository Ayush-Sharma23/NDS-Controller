    Help & Documentation

    Getting Started

    1. Setup WebSocket server on POP!_OS
    2. Enter server IP in Settings
    3. Click Connect
    4. Use the controller!

    Data Format

    The app sends button states in JSON format:

    {"buttons":{"up":false,"down":false,"left":false,"right":false,"a":false,"b":false,"x":false,"y":false,"l":false,"r":false,"start":false,"select":false},"touchscreen":{"x":0,"y":0,"touched":false}}

    Status Indicators

    • Green dot = Connected
    • Red dot = Disconnected

    Tips

    • For best performance, use 5GHz WiFi if available
    • Adjust button size and color in settings
    • Use the network scan to find available servers
    • Enable haptic feedback for better feedback (if supported)
